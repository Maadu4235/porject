## Login & Profile System - Visual Flow

```
┌─────────────────────────────────────────────────────────────┐
│                    FLOW DIAGRAM                              │
└─────────────────────────────────────────────────────────────┘

1. USER REGISTRATION (register.html)
   ├─ Fill form
   ├─ Submit to register.php
   ├─ Store in database
   └─ Redirect to login.html

2. USER LOGIN (login.html)
   ├─ Enter phone & password
   ├─ Submit to login.php
   ├─ Verify credentials in database
   ├─ Create session if valid
   └─ Redirect to index.html

3. HOME PAGE (index.html)
   ├─ On load, call check_login.php
   ├─ If logged in:
   │  ├─ Show profile dropdown in navbar
   │  ├─ Show user name in navbar
   │  └─ Profile sidebar available
   └─ If not logged in:
      ├─ Show Login/Register buttons
      └─ Hide profile sidebar

4. PROFILE SIDEBAR
   ├─ Show user name
   ├─ Show user phone
   ├─ Show user type
   ├─ Buttons:
   │  ├─ Edit Profile
   │  ├─ Settings
   │  └─ Logout

5. LOGOUT
   ├─ Call logout.php
   ├─ Destroy session
   ├─ Clear localStorage
   └─ Redirect to index.html
